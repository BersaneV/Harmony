# Harmony 0.4.12 — convites por link

Os convites agora são links HTTPS. Ao abrir, escolha “Abrir no Harmony” ou “Continuar no navegador”. Entre ou crie uma conta e confirme “Entrar na comunidade”; o convite é preservado durante o acesso. Quem instalar o Windows 0.4.12 passa a receber links harmony:// no aplicativo, inclusive quando ele já está aberto.

“Copiar link de convite” gera links de 7 dias e até 100 entradas. O campo manual também aceita links e códigos antigos. Um convite de outra instância não troca o servidor automaticamente nem envia a sessão atual para ela. Reabrir o convite de uma comunidade da qual você já participa não consome novo uso.

A instalação nova continua com https://harmony.go.altare.global configurado. Distribuição e servidor 0.4.12; voz e captura preservam a implementação anterior. Esta versão não realiza novas campanhas de FPS. Publicação manual de protótipo; canal automático separado. Assinatura Tauri/minisign não é Windows Authenticode.
