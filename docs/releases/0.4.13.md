# Harmony 0.4.13 — áudio do PC durante chamadas

Dispositivos e voz agora mostra a preferência de comunicações do Windows. O botão “Manter os outros sons no Windows” seleciona “Não fazer nada”, após informar que a mudança é permanente para o usuário Windows e vale para todos os aplicativos. Abrir o Harmony ou as configurações apenas consulta a preferência. O ajuste não altera volumes individuais, o dispositivo padrão, drivers ou serviços Bluetooth. Saia e entre na chamada após aplicar.

O Harmony lembra o microfone e a saída selecionados neste dispositivo, inclusive entre chamadas. Isso permite usar um microfone USB/do notebook junto com um fone Bluetooth, evitando abrir o microfone do Bluetooth clássico. Captura de tela pede explicitamente para manter a reprodução local e preserva o áudio do PC sem filtros de voz.

A atenuação automática do Windows e a troca A2DP/HFP são mecanismos distintos. No Windows 10, abrir o microfone Bluetooth clássico pode descartar o áudio da saída estéreo; no Windows 11 o dispositivo pode mudar para HFP com menor qualidade. A atualização não remove essas limitações de hardware/perfil. Microfone independente ou conexão com fio/USB continuam sendo alternativas.

Validação automatizada separa contratos de captura, preferências persistentes, interface/IPC no EXE Windows e instalação/assinatura. Reprodução de áudio de outro aplicativo e fones físicos com fio/Bluetooth ainda precisam de confirmação no PC afetado; o relato não foi reproduzido nesse hardware. Não declarar todos os dispositivos corrigidos a partir de testes em VM.

Protótipo gratuito, publicação manual; canal automático separado. Assinatura Tauri/minisign não é Windows Authenticode.
