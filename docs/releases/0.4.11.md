# Harmony 0.4.11 — instalar e entrar

A instalação Windows nova já usa `https://harmony.go.altare.global`. Basta abrir o Harmony, criar uma conta ou entrar. O endereço do servidor fica recolhido em “Usar outro servidor”; um endereço válido já salvo é preservado. O cliente web HTTPS continua usando sua própria origem, mantendo as instalações independentes.

Esta versão altera somente o endereço inicial e a apresentação desse campo na tela de acesso. Captura, voz, transmissão, backend e hospedagem são os mesmos da 0.4.10; não foram realizadas novas campanhas de FPS. Para começar, recomendamos 720p30. O teste anterior de 1080p exibiu cerca de 55 FPS sem congelamentos; 1440p continua experimental.

Publicação manual de protótipo, sem promoção do canal automático. A assinatura do atualizador Tauri/minisign não é assinatura Windows Authenticode.
